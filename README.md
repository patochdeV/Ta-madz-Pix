# Tama Pix Codes

Tama Pix Codes est une application mobile interactive inspirée pour Tamagotchi Pix . Découvrez et collectionnez des personnages virtuels, gérez vos favoris, explorez différentes catégories d'items, et plongez dans un univers virtuel amusant et engageant.


## Fonctionnalités

- **Collection de personnages** : Découvrez une variété de personnages virtuels avec des images optimisées.
- **Gestion des favoris** : Ajoutez et retirez des personnages de vos favoris.
- **Recherche** : Trouvez rapidement vos personnages préférés.
- **Catégories** : Explorez les items par catégories.
- **Optimisations de performance** : Images compressées et chargement optimisé pour une expérience fluide.

## Installation

1. Clonez le dépôt :
   ```
   git clone https://github.com/patochdeV/Ta-madz-Pix.git
   cd Ta-madz-Pix
   ```

2. Installez les dépendances :
   ```
   npm install
   ```

3. Lancez l'application :
   ```
   npm start
   ```

## Technologies utilisées

- **Expo** : Framework pour le développement d'applications React Native.
- **React Native** : Bibliothèque pour la création d'interfaces utilisateur natives.
- **TypeScript** : Langage de programmation typé.
- **Drizzle ORM** : ORM pour la gestion de la base de données.
